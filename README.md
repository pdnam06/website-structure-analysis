# Phân tích và xây dựng Website Template

Bài gồm hai phần: phân tích trang chủ Bootstrap trong analysis.md và xây dựng lại bố cục đơn giản với tên minh họa WebKit.

Mở index.html bằng trình duyệt; không cần Internet, JavaScript hoặc thư viện ngoài.

Có Header chứa tiêu đề nhận diện, Navigation 4 mục, Content và Footer bản quyền. Bố cục sử dụng HTML ngữ nghĩa, CSS Flexbox/Grid và responsive.
